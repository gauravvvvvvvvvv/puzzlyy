# Ambient sound recordings

Ambient audio is downloaded into `public/ambience/` by `scripts/fetch-ambience.mjs` when `npm run build` runs, using the pinned source repository revision.

Source: https://github.com/twtrubiks/moonseal/tree/8e7ef422753e12083a152671ae33aef73c40f4cd/public/audio

The original audio attribution and CC0/public-domain details are recorded in the upstream [source README](https://github.com/twtrubiks/moonseal/blob/main/public/audio/README.md).

All loops are externally sourced field recordings rather than generated noise. They are independently controlled on each listener's device, with browser playback initiated by an explicit action.
